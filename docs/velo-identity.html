Biometrics identifies a person. Credentials authorize a role.

VELO does not need to know that someone has a face — it needs to know the person producing this attestation is authorized to. Why that's a credential check, not a biometric one.

La cara, si se usa, verifica a la persona que solicita una credencial — una sola vez, el Día 0. Nunca se vuelve a chequear por caso, y nunca forma parte de lo que una prueba ZK calcula.

The face, if used at all, verifies the person applying for a credential — once, on Day 0. It is never re-checked per case, and never becomes part of what a ZK proof is computed over.

G1
proveniencia del witness
witness provenance
La biometría no cerraría este hueco. Responde "quién es el humano", no "¿corrió un motor real sobre evidencia real?". La credencial sí encaja: prueba autorización.
Biometrics wouldn't close this gap. It answers "who is the human," not "did a real engine run on real evidence?". The credential fits: it proves authorization.
G5
vinculación entre casos
cross-case linkability
Agregar biometría lo empeoraría — una cara atada a una wallet es un vínculo permanente y no rotable. La credencial ZK es la mitigación ya nombrada para G5.
Adding biometrics would make it worse — a face tied to a wallet is a permanent, un-rotatable link. The ZK credential is the mitigation already named for G5.
G8
sin modelo de revocación
no revocation model
No se puede "desaprender" una cara. Una credencial sí: árbol de Merkle de revocación, prueba de no-membresía al atestar.
You cannot un-know a face. A credential can: a revocation Merkle tree, checked by non-membership proof at attestation time.

la frase para el jurado
the line for the jury

"No usamos reconocimiento facial porque responde una pregunta distinta de la que importa. Un sistema forense no necesita probar que alguien tiene una cara — necesita probar que es un perito acreditado autorizado a emitir este análisis."
